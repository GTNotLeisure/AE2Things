# AE2Things

AE2Things is an add-on for **AE2-GTNH**. It adds large storage cells, remote terminals and multi-type automation to the ME network. The 29x branch targets GTNH 2.9.

## Suggested reading order

1. Read [Storage](storage.md) to learn how Infinity Cells work and how to link them.
2. Read [Terminals](terminals.md) if you want the Backpack Terminal or the Dual Interface Terminal.
3. Read [Buses & Automation](automation.md) for multi-type buses and bulk transfer.
4. Read [Applied Botanics](appbot.md) only if Botania is installed.

## 29x notes

> [!NOTE]
> Several features depend on optional mods: AE2FC for fluids, Thaumic Energistics for essentia, AE2Stuff for the Wireless Connector Terminal, GT5U for the Wireless Distributor, and Botania for Applied Botanics. Each module page lists its own requirements.

> [!WARNING]
> On AE2 1080+ (including GTNH 2.9), the old Thaumcraft automation blocks are deprecated and their recipes are disabled. See [Legacy & Reference](reference.md) before building around them.
